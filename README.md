# Frekvencia Generátor (Android)

Schumann-, Solfeggio- és agyhullám-frekvenciák lejátszása binaurális, izokronikus vagy tiszta hang módban.
Előtér-szolgáltatásként fut, így képernyőzárás mellett is szól. Külső függőség nincs.

Build: minden `main` ágra történő push után a GitHub Actions elkészíti az APK-t,
és feltölti a `latest` release-be (Frekvencia.apk).
